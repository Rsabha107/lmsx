# Movement Types Quick Reference

## When to Use Each Type

| Type | Icon | Use When | Examples |
|------|------|----------|----------|
| **Arrival** | ✈️ | Team arriving from airport | Flight lands → Hotel |
| **Departure** | 🛫 | Team leaving to airport | Hotel → Flight home |
| **Match** | ⚽ | Match day transport | Hotel → Stadium for game |
| **Training** | 🏃 | Training session | Hotel → Training ground |
| **Transfer** | 🚌 | One-time event movement | Hotel → Media event |
| **Daily Ops** | 🔄 | Recurring daily tasks | Daily meal/equipment runs |

---

## Quick Decision Guide

**Start here:** What are you moving?

### Moving a TEAM?
- **To/from airport?** → Arrival or Departure
- **For a match?** → Match
- **For training?** → Training
- **For an event?** → Transfer

### Moving SUPPLIES/SUPPORT?
- **Daily/recurring?** → Daily Ops
- **One-time?** → Transfer

---

## Key Difference: Transfer vs Daily Ops

| | Transfer | Daily Ops |
|-|----------|-----------|
| **How often?** | Once or occasionally | Every day |
| **What?** | Teams, officials, VIPs | Staff, supplies, equipment |
| **Why?** | Specific event | Routine operations |

**Rule of thumb:** If it happens every day → Daily Ops. If it's for a specific event → Transfer.

---

## Common Scenarios

✅ **Team Spain going to press conference** → Transfer  
✅ **Daily meal delivery to all hotels** → Daily Ops  
✅ **Team Brazil arriving from Rio** → Arrival  
✅ **Match day: Hotel to Stadium** → Match  
✅ **Daily training session** → Training  
✅ **Equipment truck restocking venues** → Daily Ops  
✅ **Team visit to sponsor event** → Transfer  
✅ **Officials going home after tournament** → Departure

---

**Still unsure? Default to Transfer for teams, Daily Ops for recurring support tasks.**
